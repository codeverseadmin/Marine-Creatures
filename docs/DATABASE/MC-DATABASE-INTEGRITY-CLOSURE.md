## 5. PRODUCT IDENTITY & MEDIA RESOLUTION

### 5.1 Investigation of the Product Identity Incident
The incident where the admin product editor failed on `blue-treasure-coral-sand` with `Product "blue-treasure-calcium-sand-" not found` was re-verified.

- **Root Cause Confirmed:** The editor form was passing the slug rather than canonical ID, with a trailing hyphen (`blue-treasure-calcium-sand-`), while API route handlers previously performed strict equality checks only on `id`.
- **Resolution Engine:** [`lib/services/product-resolution.ts`](file:///c:/Users/User/OneDrive/Desktop/Marine%20Creatures/marine-creatures/lib/services/product-resolution.ts) implements multi-tier resolution:
  1. MongoDB 24-character hexadecimal ObjectId
  2. Canonical Governance ID (`id`)
  3. Public Marketplace Slug (`slug`)
  4. Sanitized Slug (collapsing and stripping leading/trailing hyphens)
  5. Static catalogue fallback
