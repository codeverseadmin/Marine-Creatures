## 1. PROJECT SCOPE & KEY DELIVERABLES

CODEVERSE agrees to provide full-lifecycle software development, architectural design, deployment, and testing for the **Marine Creatures** web platform, including:

1. **Luxury Architectural Storefront & Portfolio:**
   - Responsive, high-conversion landing page with dark-mode luxury ocean aesthetic.
   - Interactive Promotional Banner Carousel with real-time sliding announcements.
   - Educational Marine Life Dossiers and bespoke Aquarium Design showcase.
   - Complete consultation booking and callback request pipelines.

2. **Full-Featured E-Commerce Marketplace:**
   - Filterable catalog (Marine Life, Lighting & Tech, Live Rock & Sand, Salts, Hardware).
   - Product detail views with image galleries, care guides, and live arrival guarantee badges.
   - Direct-to-WhatsApp order dispatch and client inquiry handling.

3. **Restricted Mobile-First Admin Control Center:**
   - Passcode-secured management dashboard (`/admin`).
   - Live inventory management (one-tap stock increment/decrement, pause/resume item status).
   - Dynamic sliding banner announcement creator and editor.
   - 1-tap WhatsApp quick-reply integration for incoming client leads.
   - Offline-first JSON database backup and restore system.

4. **Performance & Search Engine Optimization (SEO):**
   - High mobile responsiveness (tested for 90%+ smartphone traffic).
   - Open Graph (OG) social card previews for Facebook and WhatsApp sharing.
   - Speed optimizations and sub-second Next.js page generation.
